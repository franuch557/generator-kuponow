# Generator dubli

Strona w jednym pliku HTML: generuje dublety (2 typy z różnych rynków — wynik, podwójna szansa, gole, obie strzelą, rzuty rożne, kartki, celne strzały) z prawdziwych meczów top 5 lig i europejskich pucharów.

- Dane meczowe i statystyki: ESPN (bez klucza).
- Kontuzje, Ekstraklasa i kursy STS / Betclic / Superbet (o ile są w ofercie): API-Football z kluczem użytkownika.
- Kurs można poprawić ręcznie — zapamiętywany osobno dla każdego bukmachera.

Narzędzie poglądowe — nie przyjmuje zakładów i nie gwarantuje wygranych. 18+. Graj odpowiedzialnie.
